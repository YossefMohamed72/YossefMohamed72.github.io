دليل رفع موقع FA
==================

1) GitHub Pages — FA-GitHub-Pages-v2.zip
فك الضغط على جهازك. ارفع المحتويات داخل مجلد fa في مصدر نشر مستودع all.
يجب أن يصبح الملف في fa/index.html، وليس fa/fa/index.html.
العنوان المستهدف: https://yossefmohamed72.github.io/all/fa/
لا ترفع ملف ZIP نفسه إلى المستودع وتتوقع تشغيله؛ ارفع الملفات بعد فك الضغط.
احتفظ بإعدادات Pages الحالية إذا كان الموقع يعمل بالفعل.
إذا كان مصدر Pages هو docs، يكون مكان الملفات docs/fa؛ وإذا كان المصدر جذر الفرع يكون fa.
لا تستبدل محتويات المستودع all كله، لأن به مواقع أخرى.
خذ نسخة احتياطية من مجلد fa القديم ثم استبدل محتوياته بالنسخة الجديدة كاملة.
النسخة مضبوطة على /all/fa/ للصور وملفات JavaScript وCSS والراوتر.
توجد صفحات فعلية للروابط الداخلية حتى تعمل عند فتحها مباشرة أو تحديثها.

2) Hostinger — FA-Hostinger-v2.zip
هذه نسخة لدومين رئيسي على استضافة Web/Cloud تدعم رفع ملفات HTML، وليست Website Builder.
افتح File Manager للدومين، ثم public_html.
خذ نسخة احتياطية من الملفات القديمة قبل استبدالها.
ارفع ZIP وفك محتوياته مباشرة داخل public_html، بحيث يصبح public_html/index.html.
تأكد من رفع .htaccess الموجود بالحزمة أيضًا، ومن ظهور مجلدي assets وimages بجوار index.html.
لا تضع الملفات داخل مجلد إضافي إذا أردت تشغيل الموقع على الدومين الرئيسي.
النسخة لا تحتاج Node أو قاعدة بيانات على الخادم.
إذا أردت الرفع داخل مجلد فرعي بدل الدومين الرئيسي، يجب تعديل base وRewriteBase وإعادة البناء.
لا تخلطها بملفات WordPress أو .htaccess لموقع آخر؛ استخدم مجلد دومين مخصصًا للموقع.

3) تعديل الكود — FA-Source-Code-v2.zip
فك الضغط وافتح fa-source في VS Code.
اقرأ README-AR.md: يحتوي خريطة الملفات وأوامر التشغيل والبناء.
الأوامر من Terminal داخل مجلد المشروع:
npm ci
npm run dev

بعد التعديل:
npm run build:github
الناتج: dist/github

أو:
npm run build:hostinger
الناتج: dist/hostinger

لإنشاء النسختين:
npm run build:all

ملاحظات
- لا تشغل النسخة بالدبل كليك على index.html؛ استخدم خادم محلي أو ارفعها للاستضافة.
- ارفع مجلدَي الصور وassets كاملين؛ لا ترفع index.html وحده.
- لا تخلط ملفات assets من بناء قديم مع index.html من بناء جديد.
- الصور مضمنة، والخطوط من Google Fonts مع بدائل نظام عند عدم الاتصال.
- نموذج التواصل يجهز رسالة في تطبيق البريد؛ ليس نظام إرسال بريد تلقائيًا من الخادم.
- المشروعات والصور أمثلة توضيحية، وبيانات التواصل تحتاج مراجعتك قبل الإطلاق العام.
- لم يتم الرفع إلى GitHub أو Hostinger أو تغيير حساباتك؛ هذه ملفات جاهزة لرفعك.
